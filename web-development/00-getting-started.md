
# 🛠️ Phase 0: Getting Started with Web Development

Welcome to SYK Studio!

This is your first step toward becoming a web developer. You do not need any previous coding experience. Follow each step in order, watch the recommended lessons, and practise what you learn.

**Goal:** Understand how the web works, prepare your computer, and create your first webpage.

**Estimated time:** 2–4 days, depending on your pace.

## 📍 Step 2: Understand Frontend and Backend

Web applications often contain different parts that work together.

### Learn these concepts

- [ ] What is frontend development?
- [ ] What is backend development?
- [ ] What is a database?
- [ ] What is full-stack development?
- [ ] What roles do HTML, CSS, and JavaScript play?

Remember:

- **HTML** defines the structure of a webpage.
- **CSS** controls its appearance and layout.
- **JavaScript** adds behaviour and interactivity.
- **Backend code** handles server-side logic.
- **Databases** store information that applications need.

Choose one explanation that clearly compares these roles.

- Where the submitted information could be stored.

## 📍 Step 4: Create Your First Webpage

Now write your first lines of HTML!

### Instructions

Open `index.html` and enter the following code:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Webpage</title>
</head>
<body>
    <h1>Hello, World!</h1>
    <p>I am starting my web development journey with SYK Studio.</p>
</body>
</html>
```

Save the file and open it in your browser.

### Understand what you wrote

- `<!DOCTYPE html>` declares the HTML document type.
- `<html>` contains the document.
- `<head>` contains metadata about the page.
- `<title>` defines the browser tab title.
- `<body>` contains the visible page content.
- `<h1>` creates a main heading.
- `<p>` creates a paragraph.

You will learn HTML properly in Phase 1. For now, focus on understanding the basic structure.

Use this lesson if you need help creating or opening the file.

## 📍 Step 5: Learn to Use Browser Developer Tools

Developer tools help you inspect webpages and understand problems.

### Learn these concepts

- [ ] Open developer tools in your browser.
- [ ] Inspect an HTML element.
- [ ] View CSS styles applied to an element.
- [ ] Find the browser console.
- [ ] Understand that errors and warnings can help with debugging.

### 🎥 Learn from YouTube

[Watch: Browser Developer Tools for Beginners](https://www.youtube.com/results?search_query=Chrome+DevTools+inspect+HTML+CSS+console+beginners)

Choose a short practical tutorial demonstrating the Elements and Console panels.

### 🧪 Practice

1. Open your first webpage.
2. Right-click the heading and choose Inspect.
3. Find the corresponding HTML element.
4. Temporarily change its text or styling in developer tools.
5. Refresh the page and observe what happens.

Remember that temporary changes made in developer tools do not automatically update your saved source file.

### ✅ Check your understanding

- [ ] I can open developer tools.
- [ ] I can inspect an HTML element.
- [ ] I understand the basic purpose of the console.
